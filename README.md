# skills-public

Public Codex skills maintained by `cgarrovillo`.

## Skills

- `cg-pr-description`: Generates complete pull request descriptions from branch diffs and commit history.
- `cg-pr-review`: Performs read-only pull request and diff review with emphasis on connected code, feature risk, quality, performance, and security.
- `android-device-interaction`: Guides reliable, hierarchy-first Android device observation and automation.
- `prosncons`: Compares options in a mandatory table and explicitly explains the reasoning behind any recommendation.
- `todo`: Persists compaction-resilient lettered execution roadmaps in the canonical workspace or project artifact.
- `wyd`: Gives a brief Done, Now, and Next status update during an active session.

Each skill lives under `skills/<skill-name>/SKILL.md`.
